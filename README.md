# Kuurrss — Сабақ мәтінінен тест құрастыру және білімді тексеру жүйесі

Мектеп пен колледж мұғалімдеріне (`teacher`) сабақ мәтінінен 10 сұрақтық тест құрастырып жариялауға, ал оқушыларға (`student`) сабақ соңында онлайн тест тапсырып, нәтижесін бірден білуге арналған монолитті веб-жоба.

## Жоба рөлдері (Keycloak OIDC)
- `teacher` — сабақ мәтінінен тест құрастырады (`POST /api/quizzes`), сұрақтарды өңдеп жариялайды (`PATCH /api/questions/{id}`, `PATCH /api/quizzes/{id}`) және оқушылардың нәтижелерін көреді (`GET /api/submissions`).
- `student` — жарияланған тестті ашады (`GET /api/quizzes/{id}`), жауаптарын жіберіп ұпайын алады (`POST /api/submissions`).
- `admin` — пайдаланушылар тізімін көреді (`GET /api/users`) және ережеге сай емес тесттерді өшіреді (`DELETE /api/quizzes/{id}`).
